# 🤖 AI QA Assistant

An AI-powered QA assistant built using Python, Streamlit, and OpenAI.

The tool helps QA engineers generate, review, and analyze test scenarios using AI.

## 🚀 Features

- 💬 General QA Chat
- 🧪 Test Case Generator
- 🔌 API Test Generator
- 🐞 Bug Report Generator
- 🤖 Robot Framework Generator
- 🔍 Test Case Reviewer
- 📄 Requirement-based Test Generator
- 🎨 PBI + Figma QA Analyzer
- 📊 Excel Test Case Export

## 🎨 PBI + Figma QA Analyzer

The PBI + Figma analyzer accepts:

- Product/User Story
- Acceptance Criteria
- Business Rules
- Figma UI screenshot

It analyzes the requirement and UI design to identify:

- Requirement gaps
- Missing information
- PBI–Figma mismatches
- UI/UX issues
- Missing test scenarios
- Positive scenarios
- Negative scenarios
- Edge cases
- Boundary cases
- Validation scenarios
- Security scenarios
- Accessibility scenarios

It also generates:

- Test Cases
- Requirement Traceability Matrix
- QA Coverage Summary
- Excel Export
